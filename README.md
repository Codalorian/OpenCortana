**Your computer. Your voice. Your data.**

OpenCortana is an agentic AI voice assistant, powered by Ollama and Qwen-4B. While large tech giants create tools like these to steal your voice and chat data, OpenCortana stays private.

Here are some specifications for OpenCortana:

- Utilizes the power, flexibility, and extensibility of Python
- Includes python libraries such as ollama, webbrowser, and other various tools
- Has skills such as web surfing, coding in your IDE, setting timers, along with countless others
- Has the ability to change languages into Mandarin, Spanish, French, Russian, and Portugese
- Has the ability to change from male to female voices
- Includes text input as well in case the user does not want to speak to the program.
- Includes different modalities of input, such as images
- For advanced users, you can change the temperature and system prompt of the model.
